# CUSTOMLOVE

## At a glance

| | |
|---|---|
| **What** | A dating app prototype with a learning matchmaker: profiles, preferences, swiping, matches and chat. Team project in Advanced Software Engineering, TU Wien (winter term 2023/24). |
| **My role** | Team of five working in Scrum. Test coordinator and deputy team coordinator; project planning, Figma design and project presentations. |
| **Highlights** | Match suggestions from a logistic-regression model trained on users' like decisions.<br>Flutter app for phone and web on a FastAPI backend.<br>Containerised with Docker Compose, with Kubernetes manifests. |
| **Stack** | Flutter (Dart), Python, FastAPI, PostgreSQL, scikit-learn, Docker, Kubernetes |
