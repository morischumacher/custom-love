# CustomLove

A dating app prototype with a learning matchmaker: profiles, preferences, swiping, matches and chat. Team project in Advanced Software Engineering, TU Wien (winter term 2023/24).

## What it does

- Suggests matches with a logistic-regression model trained on users' like decisions.
- Flutter app for phone and web on a FastAPI backend.
- Containerised with Docker Compose, with Kubernetes manifests.

## My role

Team of five working in Scrum. I was test coordinator and deputy team coordinator, and took care of project planning, the Figma design and the project presentations.

## Tech stack

Flutter (Dart), Python, FastAPI, PostgreSQL, scikit-learn, Docker, Kubernetes
